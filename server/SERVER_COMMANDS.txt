Replace all placeholders before use. Do not commit real hosts, usernames, project paths, or secret locations.

Connect:

  cd <PROJECT_PATH>

  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  pip install -r server/requirements.txt

Public-data check:
  python -m tracker

Demo validation:
  python -m test_demo.run_all --skip-orders
  python -m test_demo.run_all

Live read-only validation:
  python -m test_live.run_all

Live execution:
  python main.py --live

Before live execution, confirm the current branch and commit, review configuration, inspect balances and positions, verify clock synchronization and API allowlists, and read docs/OPERATIONS.md.

Never paste API secrets into shell history or command-line arguments.
